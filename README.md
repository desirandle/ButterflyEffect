# ButterflyEffect
It’s a text based adventure game where the player picks a class (Warrior, Mage, or Rogue) that has unique stats depending on what the player chooses, moves through a story tree with several nodes, and is able to pick up items, and try to reach one of three endings (Heroic Victory, Tragic Failure, or the Secret Ending).
